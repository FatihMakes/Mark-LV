# ── MARK LVI — Python dependencies ────────────────────────────────────────────
# pip skips any line whose sys_platform marker does not match your OS, so this
# one file serves Windows, macOS and Linux. `python setup.py` runs it for you.

# Version bounds: the lower bound is what the app is developed against, the
# upper bound stops the next MAJOR release of a dependency from breaking every
# fresh clone on the day it ships. Minor and patch updates flow in freely.

# ── Video on the HUD ──────────────────────────────────────────────────────────
# Qt plays local files and direct media URLs on its own — QtMultimedia comes
# with PyQt6, so the player itself costs nothing. A YouTube page is not a video
# file, though, and yt-dlp is what turns one into a stream Qt can play. Without
# it the HUD still plays files and URLs, and YouTube links open in the browser
# with an explanation instead of failing.
#
# Deliberately UNBOUNDED, unlike everything else here. YouTube changes what it
# serves without notice and yt-dlp answers with a release; an upper bound would
# eventually pin a fresh clone to a version YouTube has already broken, which is
# the opposite of what bounds are for. Keep it current: pip install -U yt-dlp
yt-dlp

# ── Optional: running the assistant on your own models ───────────────────────
# ⚙ → ENGINE & PROVIDERS lets you replace Gemini Live with your own speech
# recognition, language model and voice — or point only the assistant's
# background requests at another provider.
#
# NOTHING IS NEEDED FOR MOST OF IT. Talking to a model — Ollama, LM Studio,
# llama.cpp, vLLM, or a hosted API like Groq, OpenAI, DeepSeek or OpenRouter —
# uses httpx, which is already above. The system's own voices (SAPI on Windows,
# `say` on macOS, espeak-ng on Linux) need no Python package at all.
#
# Two things are downloads, and both install with one click from that panel:
#
#   pip install faster-whisper   # hearing: Whisper on YOUR CPU. No GPU, no
#                                #   ffmpeg — the microphone's samples go
#                                #   straight in. ~50 languages, detected per
#                                #   sentence rather than configured.
#   pip install piper-tts        # speaking: a neural voice on this machine, in
#                                #   about 50 languages. Voices are ~60 MB each
#                                #   and fetched on demand; the assistant uses
#                                #   the one matching whatever language it just
#                                #   heard you speak.
#
# Left out of the install for the same reason as everything else in this
# section: together they are several hundred megabytes, and a fresh clone that
# only ever uses Gemini should not pay for them. Deleting providers/ removes
# the whole feature and the app runs exactly as it did before it existed.
